Tavern Ledger · logo · T-522, T-523

The TL tankard, drawn for real

The chosen mark, a T and an L that make a tankard, redrawn by hand as clean SVG from the Gemini reference. The T is the rim and stem, the L sits inside it, the base and the handle close the shape. Below: the reference beside the drawing, every file from 256 down to 16 pixels, and the icon where it will live.

Files

Every file at 256, 64, 32 and 16 px

Drawn in the browser, as a page would show them. At 32 and 16 px the main mark's gaps close up, so the small files take over there.

Pixels

What 16 and 32 px really look like

Rendered by Chrome at the real size, then enlarged so each pixel is a block. The main mark and the big tile blur at 16 px; the small variants put every edge on a pixel boundary, so the T, the L and the handle stay apart.

Record

What is what

  • Hand-drawnEvery SVG here: straight lines, arcs and a few curves, traced over the reference in a headless browser and written as path data. About 60 nodes for the whole mark.
  • AI-made, reference onlydocs/brand/reference/: the three Gemini images. Not shipped anywhere.
  • ColoursT in #ffb24a, L, body and handle in #ffd08a, ink #120d0b, from the site's palette.
  • Websitefavicon.svg (small tile), favicon-32.png, apple-touch-icon.png (180 px), mark.svg in the masthead.
  • Appicon.ico with 16, 24, 32 (small tile) and 48, 64, 128, 256 px (tile), rebuilt by tools/build_icons.py.
  • Brand assetsSocial card, tray images (16, 20, 24, 32 px), GitHub avatar and installer BMPs, rebuilt by the same script (T-523).
  • Rule 5A tankard and two letters in our own palette and type. No game logos, names, frames or look-alikes.
