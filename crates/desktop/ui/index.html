      How the overlay works

      Also in the tray menu. The overlay shows over Hearthstone only during a game, plus a small lobby panel on the Battlegrounds lobby screen. Hover a hero on the game's leaderboard to see the last board you saw of theirs. "Arrange overlay" lets you move the panels and fit the leaderboard box; until you press "Lock overlay", clicks don't reach the game. Exclusive fullscreen hides any overlay, so run Hearthstone windowed or borderless.

      Hearthstone folder

      Folder in use:

      Tavern Ledger finds the game by itself: the running game first, then Windows' install record, Battle.net and the usual folders, taking the install whose logs are newest. If it picked the wrong one, choose the folder where Hearthstone is installed (the one with Hearthstone.exe). The app only reads from it and checks client.config there; it never changes the game's files.

      Startup

      Updates

      Updates come from the project's GitHub releases.

      Error log

      When something goes wrong, the app writes a line about it to a small log file on this PC (up to 3 MB). It holds no player names, accounts, emails or keys, and it is never uploaded. A problem report includes its last lines, and you choose whether to send that report.

      Upload to the website…

      Your browser opens Tavern Ledger's sign-in page: ask for the link there, then open the email's link on this PC to sign this app in. The app never asks for your password. Accounts are created on the website.

      Signed in as

      Off until you turn it on. When it's on, each finished game's report is uploaded: heroes, card ids, places and boards. Never player names, BattleTags or ratings.

      Read from the game

      On by default. It reads two things the game already shows you: the lobby's five tribes at hero select and your own Battlegrounds rating. It reads them from the game while it runs, and only reads: it never changes the game, adds code to it or plays for you. The values stay on this PC and are never uploaded. You can turn it off below.

      The risk: reading the game's memory goes against the letter of Blizzard's End User License Agreement. Other trackers have done it for over ten years with no known bans, but Blizzard has not approved it and could act against it at any time, and the account at risk is yours. It applies while this is on; turn it off if you don't want to take it.

      Where values come from

      A value with no mark comes straight from the game's log. Every other value carries a mark, and hovering any value says where it comes from.
